## ✨ Features & Highlights

- **Tactile Editorial Layout**: An alternating aesthetic of warm paper sheets and rich charcoal night sheets.
- **GSAP-Powered Animations**:
  - Live animated pen-drawn marks (underlines, ovals, and callout arrows) that draw themselves into view as you scroll.
  - Orbiting star morphs into a heart upon hovering the signature.
  - Heading swooshes that smoothly morph between hand-drawn zig-zags and clean curves (`MorphSVG`).
  - Interactive 3D phone mockups with smooth parallax on pointer movement.
- **Scannable QR Code**: Built-in SVG QR code generator linking directly to GitHub & CV.
- **One-Click Clipboard**: Instant click-to-copy for both name (**Vedika Rana**) and email (**vedikarana001@gmail.com**) with animated feedback.
- **Accessible & Responsive**: Fully responsive across mobile, tablet, and desktop viewports, with support for `prefers-reduced-motion`.

## 💻 Getting Started Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vedika-rana/portfolio2.0.git
   cd portfolio2.0
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local dev server:**
   ```bash
   npm run dev
   ```
   *(On Windows PowerShell, you can also use `npm.cmd run dev`)*

4. **Build for production:**
   ```bash
   npm run build
   ```
